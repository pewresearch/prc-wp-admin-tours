# PRC WP Admin Tours

Host plugin for first-time wp-admin product tours, the welcome splash, and docs-site release-note splash overlays. Domain plugins register spotlight tours. This plugin matches the current screen, runs the spotlight engine or the splash overlay, and stores per-user progress.

**Package:** `@prc/wp-admin-tours`

See [docs/plugins/prc-wp-admin-tours](../../docs/plugins/prc-wp-admin-tours/index.md).
